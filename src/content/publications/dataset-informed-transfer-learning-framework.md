  sections:
    - id: "problem"
      label: "01 / THE PROBLEM"
      title: "Transfer learning usually ignores the dataset it lands on."
      duration: "20 sec"
      body:
        - "Medical imaging transfer learning starts with pretrained features, then optimizes every target sample through a largely uniform objective. That is brittle when cohorts are small, imbalanced, or heterogeneous: easy samples, decision-boundary cases, and under-represented classes do not carry the same learning difficulty."
        - "Earlier difficulty-weighted methods required hand-tuned neighbor counts, heuristic weights, and a fixed triplet margin. DITL asks whether the target dataset’s own feature geometry can supply adaptive supervision that scales from small lesion patches to large screening cohorts."
        - "The key constraint is label efficiency. If estimating difficulty required new masks or expert scores, the remedy would recreate the annotation problem transfer learning is meant to reduce. DITL instead derives its signals from class labels and self-supervised embeddings that are already available for downstream training."
    - id: "idea"
      label: "02 / THE IDEA"
      title: "Let the feature space describe what is hard."
      duration: "50 sec"
      body:
        - "First, DINO or SimCLR produces self-supervised embeddings. For each training sample, DITL examines a scale-adaptive neighborhood where k equals the ceiling of the square root of the dataset size. Local label purity becomes a difficulty score: mixed neighborhoods identify samples near class boundaries."
        - "The same analysis builds a nearest same-class representative and a farthest different-class representative. Adaptive Difficulty-Weighted Cross-Entropy emphasizes hard samples, while Adaptive Neighborhood-Representation Triplet learning uses a learnable positive margin to shape class separation without a manual margin sweep."
        - "These properties are calculated before downstream optimization and stored with the samples. That separates dataset analysis from the training loop: the loss receives an explicit difficulty weight and representative relationships, while the image backbone can still be selected for the task. The framework changes supervision, not the input data."
